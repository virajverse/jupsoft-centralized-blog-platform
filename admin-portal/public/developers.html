Architecture & Security

Dual Authentication Architecture

Blogary's hybrid architecture supports both zero-credential browser consumption and protected server-side integration.

Frontend Mode

1. Zero-Key Origin Whitelist

Best for: Client-side JavaScript, Single Page Apps, Vanilla JS, and Static HTML (e.g., DigifyNext).

How It Works:

Your client simply passes ?website=YOUR_SITE_ID. The Blogary API verifies the request's browser Origin and Referer header against your registered domain in the database.

  • Zero Secret Leakage: No API keys exposed in browser network devtools or source code.
  • Automated CORS: Cross-origin requests permitted strictly for registered hostnames.
  • Domain Lock: Scrapers cannot reuse your Website ID from unauthorized domains.
Backend Mode

2. Bearer Token / API Key Header

Best for: Server-Side Rendering (ASP.NET C#, Next.js SSR, PHP, Python, Node.js background workers).

How It Works:

Your backend server attaches an HTTP Authorization or custom header on outgoing web requests:

Authorization: Bearer YOUR_TENANT_API_KEY
x-api-key: YOUR_TENANT_API_KEY
  • Strict Tenant Isolation: The API key strictly accesses its assigned website catalog.
  • Bypass Origin Constraints: Ideal for server-to-server calls, cron jobs, and pre-rendering.
  • Encrypted Tokens Supported: Compatible with AES-128 decrypted tokens (PDP School pattern).

Vanilla JavaScript Client with Stale-While-Revalidate Caching

Production pattern used by DigifyNext: 3000ms AbortController timeout, sessionStorage instant hydration, zero API key exposure, and automated category rendering.

assets/js/cms-client.js • Vanilla JS Engine 
/**
 * Jupsoft Centralized CMS - Production Frontend Client
 * - 3000ms AbortController fast-timeout (never hangs on slow networks)
 * - In-memory & SessionStorage Stale-While-Revalidate caching (0ms instant render)
 * - Zero API Key Exposure: Origin domain whitelist authentication
 */
(function (global) {
  'use strict';

  var CMS = {
    apiUrl: 'https://blogary.jupsoft.com',
    websiteId: 'site-growth', // Replace with your Website ID from Blogary Studio
    cacheTTL: 10 * 1000 // 10 seconds cache for immediate updates
  };

  // Safe fetch with AbortController timeout
  function fetchWithTimeout(url, timeoutMs) {
    timeoutMs = timeoutMs || 3000;
    var controller = typeof AbortController !== 'undefined' ? new AbortController() : null;
    var timer = null;

    var fetchPromise = fetch(url, {
      method: 'GET',
      mode: 'cors',
      headers: { 'Accept': 'application/json' },
      signal: controller ? controller.signal : undefined
    });

    var timeoutPromise = new Promise(function (_, reject) {
      timer = setTimeout(function () {
        if (controller) controller.abort();
        reject(new Error('CMS request timed out after ' + timeoutMs + 'ms'));
      }, timeoutMs);
    });

    return Promise.race([fetchPromise, timeoutPromise]).finally(function () {
      if (timer) clearTimeout(timer);
    });
  }

  // 1. Fetch Paginated Blog List
  CMS.fetchBlogs = function (options) {
    options = options || {};
    var page = options.page || 1;
    var limit = options.limit || 12;
    var category = options.category ? '&category=' + encodeURIComponent(options.category) : '';
    var search = options.search ? '&search=' + encodeURIComponent(options.search) : '';
    
    var cacheKey = 'cms_blogs_' + CMS.websiteId + '_p' + page + '_l' + limit + category + search;
    var cached = sessionStorage.getItem(cacheKey);

    // Instant Hydration from Session Cache
    if (cached && typeof options.onCached === 'function') {
      try { options.onCached(JSON.parse(cached)); } catch(e) {}
    }

    var endpoint = CMS.apiUrl + '/v1/blogs?website=' + encodeURIComponent(CMS.websiteId) +
                   '&page=' + page + '&limit=' + limit + category + search;

    return fetchWithTimeout(endpoint, 3500)
      .then(function (res) {
        if (!res.ok) throw new Error('CMS HTTP ' + res.status);
        return res.json();
      })
      .then(function (payload) {
        sessionStorage.setItem(cacheKey, JSON.stringify(payload));
        return payload;
      });
  };

  // 2. Fetch Single Blog Post by Slug
  CMS.fetchBlogBySlug = function (slug) {
    var endpoint = CMS.apiUrl + '/v1/blogs/' + encodeURIComponent(slug) +
                   '?website=' + encodeURIComponent(CMS.websiteId);

    return fetchWithTimeout(endpoint, 3500)
      .then(function (res) {
        if (!res.ok) throw new Error('Blog article not found');
        return res.json();
      });
  };

  // 3. Fetch Taxonomy Categories
  CMS.fetchCategories = function () {
    var endpoint = CMS.apiUrl + '/v1/categories?websiteId=' + encodeURIComponent(CMS.websiteId);
    return fetchWithTimeout(endpoint, 3000).then(function(r) { return r.json(); });
  };

  global.BlogaryClient = CMS;
})(window);

ASP.NET C# Server-Side Implementation (.NET Framework / Core)

Production pattern used by Prabhu Dayal Public School (pdpschool.com): WebClient/HttpClient with TLS 1.2+ protocol, AES-128 token or direct Bearer key, and IIS URL Rewriting.

blog.aspx.cs • ASP.NET Web Forms / MVC Code-Behind 
using System;
using System.Configuration;
using System.Net;
using System.Text;
using System.Web;
using System.Web.UI;

public partial class blog : System.Web.UI.Page
{
    public string BlogsJson = "null";

    protected void Page_Load(object sender, EventArgs e)
    {
        if (!IsPostBack)
        {
            LoadBlogs();
        }
    }

    private void LoadBlogs()
    {
        try
        {
            // Enforce modern TLS security protocol (required for HTTPS AWS / VPS APIs)
            ServicePointManager.SecurityProtocol = (SecurityProtocolType)3072 | SecurityProtocolType.Tls12;

            string host = ConfigurationManager.AppSettings["CmsHost"] ?? "https://blogary.jupsoft.com";
            string siteId = ConfigurationManager.AppSettings["CmsSite"] ?? "site-pdpschool";
            string apiKey = ConfigurationManager.AppSettings["CmsApiKey"] ?? "";

            string url = host.TrimEnd('/') + "/v1/blogs?website=" + siteId + "&limit=50";

            using (WebClient client = new WebClient())
            {
                client.Encoding = Encoding.UTF8;
                client.Headers[HttpRequestHeader.UserAgent] = "BlogaryClient/1.0 (Windows NT 10.0)";
                
                // Attach Authorization header if server-side API key is configured
                if (!string.IsNullOrEmpty(apiKey))
                {
                    client.Headers[HttpRequestHeader.Authorization] = "Bearer " + apiKey;
                }

                BlogsJson = client.DownloadString(url);
            }
        }
        catch (Exception ex)
        {
            // Log error safely and provide empty fallback to prevent page crash
            BlogsJson = "{\"success\":false,\"data\":[]}";
        }
    }
}

Next.js 14/15 App Router (Incremental Static Regeneration)

Next.js Server Component pattern with next: { revalidate: 60 }, automatic dynamic OpenGraph meta tags, and Google Schema.org JSON-LD injection.

app/blog/[slug]/page.tsx • Next.js 14/15 Server Component 
import { Metadata } from 'next';
import { notFound } from 'next/navigation';

interface Props {
  params: { slug: string };
}

// 1. Fetch with 60-second Incremental Static Regeneration (ISR)
async function getArticle(slug: string) {
  const res = await fetch(
    `https://blogary.jupsoft.com/v1/blogs/${slug}?website=${process.env.BLOGARY_SITE_ID}`,
    {
      headers: {
        'x-api-key': process.env.BLOGARY_API_KEY || '',
      },
      next: { revalidate: 60 }, // Sub-50ms static cache with background revalidation
    }
  );

  if (!res.ok) return null;
  const json = await res.json();
  return json.data;
}

// 2. Automated SEO Metadata Generation
export async function generateMetadata({ params }: Props): Promise {
  const post = await getArticle(params.slug);
  if (!post) return { title: 'Article Not Found' };

  return {
    title: post.seo?.metaTitle || post.title,
    description: post.seo?.metaDescription || post.excerpt,
    openGraph: {
      title: post.seo?.ogTitle || post.title,
      description: post.seo?.ogDescription || post.excerpt,
      images: [post.seo?.ogImage || post.featuredImage],
      url: post.seo?.canonicalUrl,
    },
  };
}

// 3. Article View Page Component
export default async function BlogPostPage({ params }: Props) {
  const post = await getArticle(params.slug);
  if (!post) notFound();

  return (
    <article className="max-w-4xl mx-auto px-4 py-12">
      {/* Google Rich Snippet JSON-LD */}
      {post.schemaJsonLd && (
        <script
          type="application/ld+json"
          dangerouslySetInnerHTML={{ __html: JSON.stringify(post.schemaJsonLd) }}
        />
      )}

      <h1 className="text-4xl font-extrabold mb-4">{post.title}</h1>
      <div className="text-gray-500 mb-8">
        By {post.authorName} • {new Date(post.publishedAt).toLocaleDateString()} • {post.readTimeMinutes} min read
      </div>

      {post.featuredImage && (
        <img
          src={post.featuredImage}
          alt={post.featuredImageAlt || post.title}
          className="w-full rounded-2xl mb-8 object-cover"
        />
      )}

      <div
        className="prose dark:prose-invert max-w-none"
        dangerouslySetInnerHTML={{ __html: post.content }}
      />
    </article>
  );
}

API Specification

REST API Endpoint Reference

All endpoints are served over HTTPS from https://blogary.jupsoft.com/v1.

GET /v1/blogs List Published Articles

Returns a paginated list of published articles for the specified website with summary cards, cover images, and taxonomy tags.

Parameter Type Required Description
website string Yes* Website ID or registered domain (e.g. site-growth or digifynext.com). *Optional if Bearer key provided.
page number No Page number for pagination. Default: 1.
limit number No Articles per page. Default: 10. Max: 50.
category string No Filter by category slug (e.g. seo, education).
tag string No Filter by tag slug (e.g. admissions).
fresh string No Pass 1 to bypass edge caching and fetch live real-time database state.
GET /v1/blogs/:slug Single Blog Post Detail

Returns the full article body HTML, author biography, canonical URL, OpenGraph tags, and pre-formatted Schema.org JSON-LD markup.

Parameter Type Required Description
:slug string Yes The unique URL slug of the blog article (e.g. seo-trends-modern-brands-should-watch-closely).
website string Yes* Website ID or registered domain.
fresh string No Pass 1 to bypass edge caching for draft preview.
GET /v1/blogs/latest

Fetches the 5 most recently published articles. Ideal for footer widgets and sidebar "Recent Posts" carousels.

Parameters: website, limit (default 5).
GET /v1/blogs/popular

Retrieves the highest-viewed trending articles ranked by real-time privacy-friendly view analytics.

Parameters: website, limit (default 5).
GET /v1/categories

Retrieves the taxonomy category list with counts and hierarchical parent-child relationships for category tabs.

Parameters: websiteId.
POST /v1/revalidate

Purges Redis edge cache instantly when an article is edited or published. Triggered automatically by Blogary webhooks.

Body: {"website": "...", "slug": "..."}

Production Integration Checklist

Before launching your Blogary integration live, verify these essential items:

✓
1. Whitelist Production Domain:
Ensure your exact domain (e.g., https://yourdomain.com and www.yourdomain.com) is entered in Blogary Studio under Website Settings.
✓
2. Set Fallback Featured Image:
Always provide a fallback cover image in your frontend rendering logic in case an author creates an article without a cover.
✓
3. Implement Canonical & OG Tags:
Extract post.seo.canonicalUrl and post.seo.ogImage to maximize search engine indexing and social media shares.
✓
4. Add Google Schema.org JSON-LD:
Directly inject the pre-built post.schemaJsonLd script into your HTML head to unlock Google Rich Snippets.
✓
5. Enforce Safe Request Timeouts:
Use an AbortController with a 3000ms-4000ms threshold so your frontend renders cleanly even on flaky mobile connections.
✓
6. Cache Invalidation Webhook:
If using Static Site Generation (Next.js/Nuxt), configure Blogary Studio's Webhook URL to call your site's /api/revalidate endpoint.
